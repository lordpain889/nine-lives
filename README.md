# Nine Lives (браузерное демо)

Пиксельное дарк-фентези про котов. 2D souls-like в браузере: выбери класс кота,
пройди проклятое кладбище, победи Стража. Девять жизней — не гарантия.

> Эта Phaser-версия — играбельный прототип/демо. Основная разработка игры
> переехала в Godot (репо `nine-lives-godot`) с прицелом на Steam и кооп.

**Стек:** Phaser 3 + Vite + TypeScript. Весь пиксель-арт генерируется кодом
(`tools/sprites`): матрицы символов → детерминированные PNG-спрайтшиты,
палитра — ровно 16 цветов.

## Игра

- 4 класса: Рыцарь, Маг, Наёмник, Асасин — разные статы, оружие и перекаты
- Souls-боёвка: стамина, перекат с i-frames, читаемые замахи врагов
- Алтари: отдых лечит и возрождает врагов; чекпоинты
- Смерть роняет «рыбьи кости» на месте гибели — вернись и забери
- Босс: Страж Кладбища (2 атаки, фаза 2 ниже 50% HP)

**Управление:** WASD/стрелки — ходьба, J/Z/Space — удар, K/X/Shift — перекат,
H/F — фляга, E — алтарь.

## Разработка

```bash
npm install
npm run dev      # dev-сервер на :3030
npm run sprites  # перегенерировать спрайтшиты из tools/sprites/defs
npm run build    # tsc + vite build → dist/
```

Арт правится только в `tools/sprites/defs/*.ts` (PNG — артефакты генерации,
коммитятся). Баланс — один файл: `src/config/gameData.ts`.
